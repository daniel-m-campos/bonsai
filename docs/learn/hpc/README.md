# The HPC track

How bonsai got fast, taught from the machine up. Two subtracks, one per plane.

- **[CPU](cpu/README.md)**: the systematic primer. Cache lines, the histogram fill's parallel forms, and what coordination costs. Built from the leaf-wise campaign (issue #367, PR #369).
- **[GPU](gpu/README.md)**: the episodes. Six cases from the device engine's history, each one a measured lever or a refutation.

Start with CPU chapter 1 if you want the machine model; start with any GPU case if you want a story. The [algorithm track](../../guide/README.md) teaches gradient boosting itself.
